This is an UpSet plot. It shows every combination of home languages reported for a child, which a Venn diagram cannot do once there are more than three languages.

Horizontal bars (left)
Total children who use each language in any combination. English 764 means 764 children have English as one of their home languages, alone or with others.
Vertical bars (top)
Children with that exact combination. Each column is one specific set of languages.
Dot matrix
Filled dots show which languages make up each column. A line joins the dots of a multilingual combination; a single dot is a one-language home.
Shading
Lighter bars are one-language homes; darker bars have more languages. The dots carry the same information, so shading is never the only cue.
Hover or tab
Move over a column or a language bar for the exact count. Columns are keyboard focusable.
